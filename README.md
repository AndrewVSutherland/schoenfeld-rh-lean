# Schoenfeld's bound for ψ is equivalent to the Riemann hypothesis (Lean 4, Mathlib only)

```lean
-- Challenge.lean (imports only Mathlib); proved in Solution.lean
theorem schoenfeld_strict_bound_iff_riemannHypothesis :
    (∀ x : ℝ, 73.2 ≤ x → |Chebyshev.psi x - x| < Real.sqrt x * Real.log x ^ 2 / (8 * Real.pi)) ↔
      RiemannHypothesis
```

The inequality is Theorem 10, (6.2) of L. Schoenfeld, [*Sharper bounds for the Chebyshev functions θ(x) and
ψ(x). II*](https://pubs.ams.org/MCOM/1976-30-134/S0025-5718-1976-0457374-X), Math. Comp. 30 (1976), 337–360: under the Riemann hypothesis, |ψ(x) − x| < √x log²x/(8π) for x ≥ 73.2.
`Chebyshev.psi`, `Real.sqrt`, `Real.log`, `Real.pi` and `RiemannHypothesis` are Mathlib's. The theorem is stated in
`Challenge.lean`, is judged by `lake comparator`, and depends only on the axioms `propext`, `Classical.choice`,
`Quot.sound`.

This repository proves an equivalence. It proves neither the Riemann hypothesis nor the bound.

- **Lean `v4.35.0`, Mathlib at `56a00585` (tag `v4.35.0`). Mathlib is the only Lake dependency.** Everything else is
  in this repository.
- **`lake comparator --paranoid` accepts it**: Lean's kernel and the five external checkers bundled with the
  toolchain (leanchecker-paranoid, lean4lean, nanoda, con-leche, con-ron) accept the theorem. Commands and expected
  output: [VERIFY.md](VERIFY.md). Logs of runs on this repository: <https://math.mit.edu/~drew/shortgrh/>.

## How the proof goes

**Bound ⟹ RH** (`SchoenfeldRH/Converse*.lean`). The bound gives ψ(x) − x = O(x^(1/2+ε)) for every ε > 0; then
−ζ′/ζ(s) − s/(s−1) continues analytically to Re s > 1/2, so ζ has no zeros there, and the functional equation gives
Mathlib's `RiemannHypothesis`. The analytic part is `RHPrimeError/Converse.lean` from
[AIOvernight/rh-prime-error](https://github.com/AIOvernight/rh-prime-error) @ `c55887da` (Apache-2.0), unchanged.

**RH ⟹ bound for x ≥ 30000** (`SchoenfeldRH/Xi/*`, `Explicit*`, `ZeroSum/*`, `Large.lean`, `LargeRH.lean`). The
argument was designed for this project so that no explicit zero-counting theorem (Riemann–von Mangoldt with constants)
and no large computation is needed.

1. *Smoothed explicit formula* (`explicit_formula_mu`). For natural x and real μ (μ > 0 or μ < −1, μ ∉ {2, 4, …}),
   Σ_{n<x} Λ(n)(1 − (n/x)^μ) = μx/(μ+1) − log 2π·(1 − x^(−μ)) + … − Σ_ρ m_ρ μ(x^ρ − x^(−μ))/(ρ(ρ+μ)) − (trivial zeros),
   the Mellin kernel being μx^s/(s(s+μ)). With μ = λ this is a lower bound for ψ(x); with μ = −λ, after adding
   x^λ·(−ζ′/ζ(λ)), an upper bound. Under RH (ρ = 1/2 + iγ) both zero sums are at most √x·λ·W(B) with B = λ ± 1/2 and
   W(B) = Σ_ρ m_ρ / √((1/4 + γ²)(B² + γ²))  (`zeroSumW`). Results: `psi_sub_le_of_RH`, `sub_psi_le_of_RH`.
2. *The zero sum without counting zeros* (`zeroSumW_le_of_RH`). Hadamard's product for ξ gives, under RH, the exact
   identity Σ_ρ m_ρ β/(β² + γ²) = ξ′/ξ(1/2 + β) for β > 0, and ξ′/ξ at a real point is elementary (Γ′/Γ(z) ≤ log z,
   ζ′/ζ < 0). Since 1/√((1/4+γ²)(B²+γ²)) is an average of the kernels 1/(β²+γ²) over 1/2 ≤ β ≤ B
   (∫₀^{π/2} dθ/(p cos²θ + q sin²θ) = π/(2√(pq))), this yields B·W(B) ≤ log²(B/π)/(2π) + 1/2 for B ≥ 50.
3. *Conclusion* (`schoenfeld_large_of_contracts`, `schoenfeld_large_of_RH`). With λ = √n ± 1/2 the two bounds are below
   √n log²n/(8π) for every natural n ≥ 30000, with room to pass to real x.

The analytic inputs about ξ come from the vendored PrimeNumberTheoremAnd modules: `Complex.riemannXi`
(ξ(s) = (s(s−1)Λ₀(s) + 1)/2) is entire of order 1 and has a Hadamard factorization, with the resulting formula for
ξ′/ξ as a sum over its zeros. `SchoenfeldRH/Xi/` adds what this proof needs on top of that: the zeros of ξ lie in the
open critical strip, ξ′/ξ(1) = −ξ′/ξ(0) = 1 + γ/2 − log(4π)/2, the sum over the zeros regrouped with multiplicities,
and ζ′/ζ in terms of ξ′/ξ. The digamma series and log(x − 1) ≤ Γ′/Γ(x) ≤ log x are in `SchoenfeldRH/Lemmas/p4/`.

**The range 73.2 ≤ x ≤ 30000** (`SchoenfeldRH/Small*`). One kernel evaluation in exact natural-number arithmetic: a walk
over n = 1, …, 30000 that maintains lcm(1..n) (so ψ(n) = log lcm(1..n) exactly) and checks two integer inequalities on
each of 139 intervals; the soundness theorem `Small.bound_of_walk` turns this into the real inequality. The certificate
(`Small.walk_data`, 5 kB of data) is generated by `scripts/small/gen.py`.

The threshold 73.2 is Schoenfeld's and is not sharp: in floating point the inequality also holds on [59, 73.2].
